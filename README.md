# Tic Tac Toe

A simple, interactive Tic Tac Toe game built with HTML, CSS, and JavaScript.

## Features

- Play against another player
- Clean and intuitive user interface
- Real-time game state updates
- Win detection and game reset functionality

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and layout
- `script.js` - Game logic and interactivity

## How to Play

1. Open `index.html` in your web browser
2. Player X goes first, click a square to make your move
3. Players alternate turns
4. First player to get three in a row (horizontally, vertically, or diagonally) wins
5. Click reset to start a new game

## Getting Started

Simply clone or download this repository and open `index.html` in your favorite web browser to play!
